# Global Courier Tracker

A lightweight starter app for tracking international courier shipments.

## Features

- Track by courier + tracking number.
- Generates a multi-country shipment route.
- Displays shipment timeline with statuses and timestamps.

## Run locally

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Notes

This is a demo UI with deterministic sample tracking events based on your input.
Integrate with real courier APIs (DHL, FedEx, UPS, USPS, etc.) for production use.
